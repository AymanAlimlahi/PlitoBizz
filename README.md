# PilotBizz

Open this folder in Visual Studio Code.

## Preview

Open index.html with the Live Server extension, or open index.html directly in a browser.

## Edit

The complete website is in index.html: CSS is inside the style block and JavaScript is inside the script type="module" block.

Google Fonts and Lenis load from the internet. The site falls back to native scrolling if Lenis is unavailable.

The project form prepares an email draft; it does not send requests automatically.

## Social links
Search for SOCIAL_LINKS in index.html. Add your Instagram, TikTok, Facebook and WhatsApp URLs there. Until configured, buttons display a notice instead of opening a placeholder page.
